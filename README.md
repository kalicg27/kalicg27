## 🛠️ Featured Projects

### 🧰 [KaliToolSet — Unreal Engine 5 Editor Utility Plugin](https://github.com/kalicg27/KaliToolSet)
**C++ | Slate UI | Unreal Editor Internals | Reflection (`FProperty`)**

A custom C++ and Slate-based UE5 Editor plugin built to streamline level design, technical art, and gameplay prototyping workflows.
* **Batch Blueprint Property & Component Modifier:** Inspects Blueprint Class Default Objects (CDOs) and component hierarchies (`USimpleConstructionScript`) to batch-edit actor defaults and sub-component properties via `IDetailsView`.
* **Template-Based Asset Generation:** Accelerates prototyping with one-click Blueprint creation from categorized gameplay templates and direct DataTable access.
* **Viewport Debug Overrides:** Provides instant viewport rendering toggles (`Wireframe`, `Collision`, `Bounds`) directly on `FEditorViewportClient`.
* **Native Slate Architecture:** Built as a dockable multi-tab editor window (`SDockTab`, `SCompoundWidget`, `SWidgetSwitcher`) integrated into the Content Browser context menu (`FContentBrowserMenuExtender`).

### 🎮 [UE5 C++ Gameplay & Physics Interaction Sandbox](https://github.com/kalicg27/gamedev)
**C++ | Unreal Engine 5 | Physics & Component Architecture**

A modular gameplay mechanics sandbox exploring custom `UActorComponent` and `USceneComponent` design, physics manipulation, and runtime input binding[cite: 11, 13, 16].
* **Physics Object Manipulation (`UGrabber`):** Sweep-trace detection paired with `UPhysicsHandleComponent` for picking up, carrying, and releasing physics-simulating actors[cite: 11].
* **Modular Movement & Trigger Systems (`UMover`, `UTriggerComponent`):** Frame-rate-independent actor interpolation (`FMath::VInterpConstantTo`)[cite: 12] and tag-filtered overlap volumes[cite: 18, 19].
* **Event-Driven Weapon & Pickup Flow (`UTP_WeaponComponent`, `UTP_PickUpComponent`):** Dynamic multicast delegates (`FOnPickUp`) that attach skeletal mesh weapons to character sockets and dynamically bind `EnhancedInput` mapping contexts[cite: 14, 15, 16, 17].
